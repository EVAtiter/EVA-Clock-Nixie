# EVA Clock Nixie

[English](README.md) | **日本語**

ニキシー管の時計をデスクトップに置くアプリです。

橙色に灯る数字は写真の加工ではなく、管の輪郭も数字の曲がり具合も一本ずつ描き
起こしています。数字は「曲げた一本の針金」として作られ、にじみ・中間色・発光の芯の
三層が重なって、あのオレンジの灯りになります。

消灯している桁にはガラス管とカソードの積層がそのまま残ります。時刻が変わるたびに、
灯る管と灯っていない管が静かに入れ替わります。

メニューバーに常駐し、Dock にはアイコンを置きません。

## できること

- 12 時間制 / 24 時間制の切り替え
- ウインドウサイズを 25%〜150% で調整
- 透明度を 0%〜100% で調整（完全に透けてもドラッグできます）
- 最前面に固定（Floating）
- ドラッグ移動を禁止（Fixed Position）
- 壁紙にピン留めして、すべての操作スペースに表示（Widget）
- 他のアプリが全画面のときは自動で退避し、解除で戻る
- 時報チャイム（3 秒前からの予告音つき、音量調整可）
- ログイン時に自動起動
- ウインドウの位置はディスプレイごとに記憶。スリープ復帰やモニター構成の変更のあとも、
  元の場所へ戻ります

## 操作

設定は、メニューバーのアイコン、または時計を右クリックして開きます。サイズと透明度は
スライダーでその場で変えられます。

## 動作環境

macOS 13.0 Ventura 以降 / Apple Silicon 搭載モデル
